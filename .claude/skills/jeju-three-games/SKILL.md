# 제주 three.js 프로젝트 설명서 (C:\vibe\day4)

## 먼저 알아둘 것
- 사용자는 **한국어**로 대화한다. 답변도 한국어로, 쉽고 짧게 쓴다.
- 화려하고 풍성한 결과물을 좋아한다. 작업이 끝났으면 "끝났다"고 분명히 말한다. ("시간이 얼마나 남았어?"라고 두 번 물었다.)
- 모든 페이지는 **HTML 파일 하나**로 되어 있고, three.js(r160)를 인터넷(jsDelivr)에서 불러온다. 그래서 인터넷이 필요하다.

| `rpg.html` | 「탐라의 신화」. 제주 신화 3D 액션 RPG. 신(설문대할망, 자청비, 영등할망, 강림도령, 백록)과 대화하고 퀘스트를 받아 도채비 등을 물리친다. 아이템 55종 이상, 신술 4개, 정령 동료, 보스 2명, 저장 기능이 있다. |
| `transformer.html` | 「AI는 어떻게 말을 할까요?」 유치원생도 이해하는 트랜스포머 설명 애니메이션(9장면). 로봇 친구, 다음 말 맞히기, 토큰(레고 조각), 임베딩(뜻 나라), 어텐션(빛줄기), 층 쌓기, 온도 슬라이더와 다음 말 뽑기, 학습(책 읽고 다이얼 돌리기), 정리. 자동 재생 + 한국어 음성, 이전/다음/멈춤 버튼. 코드 구조: `SC` 배열에 장면 객체(`lines`, `build`, `phase`, `update`)를 넣는 방식이고, 새 장면은 같은 형태로 추가한다. |
| `.gitignore` | `jeju_anim/` 폴더를 올리지 않도록 막는다. |

`jeju_anim/` 폴더는 사용자의 블렌더 작업물이다. **절대 건드리거나 커밋하지 않는다.**

## 조작법
- **귤이 게임**: `Space` 또는 `↑` 점프(공중에서 한 번 더 누르면 2단 점프, 오래 누르면 더 높이), `←` `→` 또는 `A` `D` 좌우 길 바꾸기, `P` 일시정지, `M` 음악, `V` 음성. 캐릭터 **바로 뒤 위에서 보는 시점**이다(옆에서 보는 시점은 공간 판단이 어려워 사용자가 바꿔 달라고 했다).
- **RPG**: `WASD` 이동, 마우스 우클릭 드래그 시점 회전, `Space`·좌클릭 공격, `1`~`4` 신술, `Shift` 구르기, `E` 대화·상호작용, `I` 가방, `J` 퀘스트, `Q` 체력약, `R` 신기약. PC 전용이다.

## 코드 구조 (쉽게 설명)
### game.html
- **길 만들기**: 길은 6칸짜리 "행"을 계속 이어 붙인다. 행마다 도로, 돌담, 나무 등 장식과 장애물, 감귤이 정해진다. 지나간 행은 재활용한다.
- **캐릭터 움직임**: 앞으로는 자동으로 달리고, 점프는 중력(`GRAV`)과 점프 힘(`JUMP_V`)으로 계산한다. 바다 틈에 빠지면 목숨이 줄고 앞쪽 땅에서 다시 시작한다.
- **카메라**: `updateCamera` 함수. 뒤 6.5칸, 위 4.8칸 위치(`P.x - 6.5`, `4.8`)에서 앞을 본다. 시야가 답답하면 이 숫자를 바꾼다.
- **소리**: 효과음과 배경음악은 파일 없이 코드로 만든다(Web Audio). 음성은 브라우저의 음성 합성(`speechSynthesis`)을 쓴다.
- **돌하르방 모델**: `statueGeo`. 벙거지, 눈, 코, 미소, 손, 현무암 구멍, 이끼까지 표현했다.

### rpg.html
- **아이템 표**(`ITEMS`): `it('아이디','이름','아이콘','종류',등급,{능력치},가격,'설명')` 한 줄이 아이템 하나다. 새 아이템은 이 형식으로 추가한다.
- **적 표**(`EN`)와 **구역 표**(`ZONES`): 적의 체력, 공격력, 드롭 아이템과 나오는 위치를 정한다.
- **퀘스트 표**(`QUESTS`)와 **NPC 표**(`NPC_DEF`): 목표(처치, 아이템 모으기, 제단 활성화)와 보상, 대사를 정한다.
- **지형**: `H(x, z)` 함수가 땅 높이를 계산한다. 건물이나 몬스터를 놓을 때 `H`로 높이를 맞춘다.
- **신술**: `SK` 배열. 마나(`mp`), 재사용 시간(`cd`), 열리는 레벨(`lv`)을 바꿀 수 있다.
- **저장**: 브라우저 저장소(`localStorage`)에 `jeju_myth_rpg_v1` 이름으로 자동 저장된다.

## 이 컴퓨터에서 알아낸 것 (중요)
- **Python과 Node가 설치되어 있지 않다.** `python -m http.server`는 쓸 수 없다. 사용자에게는 HTML 파일을 더블클릭해서 열거나 VS Code의 Live Server 확장을 쓰라고 안내한다.
- 앱 안의 브라우저가 `file://`과 `localhost` 주소를 열어 주지 않아서, **Claude는 지금까지 만든 페이지를 한 번도 직접 실행해 보지 못했다.** 모든 코드는 "읽고 점검만 한" 상태다. 그래서 완성했다고 말할 때 "브라우저에서 실행해 보지는 못했다"고 솔직하게 알린다. 화면이 비면 사용자에게 F12를 눌러 Console 탭의 빨간 오류 메시지를 알려 달라고 한다.
- **이미 겪은 실수** (같은 실수를 피할 것):
  - `Object.assign`으로 `Object3D.position`을 바꾸면 오류가 난다. `.position.set(...)`을 쓴다.
  - 도우미 함수가 `SphereGeometry`, `CylinderGeometry`의 뒤쪽 인자를 넘겨 주지 않으면 모양이 틀어진다.
  - 선언하지 않은 변수를 쉼표로 이어 쓰면 모듈 코드가 바로 멈춘다.
- 아이콘 이모지는 오래된 것(Windows에서 잘 보이는 것)을 쓴다.

## Git / GitHub 상태
- `C:\vibe\day4`에 `git init -b main`을 했고 커밋은 1개다(`index.html`, `space.html`, `.gitignore`).
- `jeju.html`, `game.html`, `rpg.html`, 그리고 이후 수정한 `index.html`은 **아직 커밋하지도 올리지도 않았다.**
- `gh` 명령이 없어서 저장소를 새로 만들 수 없다. 사용자는 "기존 저장소 URL을 쓰겠다"고 했지만 **URL을 아직 알려 주지 않았다.** 올리기 전에 반드시 URL을 물어본다. 그 뒤 `git remote add origin <URL>` 후 `git push -u origin main`을 한다.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`를 붙인다. Git 사용자 이름과 이메일은 이미 설정되어 있다.
