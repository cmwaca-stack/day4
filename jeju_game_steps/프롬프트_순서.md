# 바이브코딩 실습 — 「돌돌이의 귤 바람」 제주 게임 만들기

> 코드는 한 줄도 직접 쓰지 않습니다. 아래 프롬프트를 **순서대로 하나씩** AI에게 입력하고,
> 매번 `jeju_game.html`을 더블클릭해서 바뀐 모습을 확인한 뒤 다음 단계로 넘어갑니다.
> 각 단계의 정답 예시는 이 폴더의 `step1.html` ~ `step9.html`에 있어요. (막히면 열어 보세요.)

**공통 규칙** — 실제 회사 로고·남의 캐릭터·사진·이모지는 쓰지 않고, 그림은 전부 코드로 그립니다.

---

## 1단계 — 무대 만들기 (배경)

```
jeju_game.html 파일 하나로 브라우저 게임 화면을 만들어 줘.
화면 전체를 캔버스로 채우고, 제주도 바닷가 풍경을 코드로 직접 그려 줘.
위에서부터 그라데이션 하늘, 구름, 한라산, 바다, 돌담, 노란 유채꽃밭 순서로.
구름은 천천히 흘러가고 유채꽃은 살랑살랑 흔들리게 해 줘.
```

👀 확인: 더블클릭하면 움직이는 제주 풍경이 보이나요?

## 2단계 — 주인공 등장

```
유채꽃밭 위에 돌하르방을 닮은 귀여운 오리지널 돌 캐릭터 '돌돌이'를 그려 줘.
회색 몸, 둥근 모자, 큰 눈, 긴 코, 발그레한 볼, 머리 위에는 귤 바구니를 들고 있어.
키보드 ←→ (또는 A, D), 마우스 움직임, 손가락 터치로 좌우로 움직이게 해 줘.
```

👀 확인: 키보드·마우스·폰 터치로 다 움직이나요?

## 3단계 — 귤이 떨어진다!

```
하늘에서 귤이 하나씩 떨어지게 해 줘. 귤은 주황색 공에 초록 잎을 붙여서 그려.
돌돌이 바구니로 받으면 점수 +10, 놓쳐서 땅에 떨어지면 그냥 사라져.
왼쪽 위에 점수를 크게 보여 줘.
```

## 4단계 — 진짜 게임으로 (위험물 · 생명 · 시작/끝)

```
가끔 검은 현무암 돌도 떨어지게 해 줘. 돌을 받으면 생명이 하나 줄어들어.
생명은 3개로 시작하고 오른쪽 위에 하트로 보여 줘.
게임 시작 화면(제목: 돌돌이의 귤 바람, 시작 방법 안내)과
게임 오버 화면(점수, 최고 점수, 다시하기)을 만들어 줘.
최고 점수는 브라우저에 저장해서 새로고침해도 남아 있게 해 줘.
스페이스, 엔터, 클릭, 터치 어떤 걸로도 시작/다시하기가 되게 해 줘.
```

👀 확인: 여기까지 오면 이미 "끝까지 플레이 가능한 게임"이에요!

## 5단계 — 점점 어려워지게 + 제주 바람

```
시간이 지날수록 레벨이 올라가게 해 줘. 레벨이 오르면 귤이 더 빨리, 더 자주 떨어지고 돌도 많아져.
그리고 제주도답게 바람이 불게 해 줘. 바람이 왼쪽·오른쪽으로 바뀌면서 떨어지는 귤을 옆으로 밀어.
화면 위쪽에 레벨과 바람 방향을 화살표로 보여 주고, 바람 줄무늬도 날려 줘.
시간이 흐르면 하늘이 아침 → 노을 → 밤(별)으로 바뀌게 해 줘.
```

## 6단계 — 화려하게! (이펙트)

```
게임을 훨씬 화려하게 만들어 줘.
- 귤을 받으면 주황 파티클이 팡 터지고 "+10" 글자가 떠올라
- 연속으로 받으면 콤보 숫자를 크게 보여 주고, 10콤보마다 점수 배수가 올라가
- 돌에 맞으면 화면이 흔들리고 빨갛게 번쩍여
- 구름·한라산·꽃밭이 돌돌이 움직임에 따라 다른 속도로 움직이는 패럴랙스 효과
- 해에는 빛나는 글로우
```

## 7단계 — 소리 넣기

```
효과음과 배경음악을 넣어 줘. 음악 파일은 쓰지 말고 Web Audio로 직접 소리를 만들어.
귤 받을 때 '띵'(콤보가 오를수록 음이 올라가게), 돌에 맞을 때 '쿵', 레벨 업, 게임 오버 소리.
배경에는 잔잔한 멜로디가 반복되게. M 키나 오른쪽 위 스피커 버튼으로 소리를 끌 수 있게 해 줘.
```

## 8단계 — 특별 아이템과 피버 타임

```
특별 아이템을 추가해 줘.
- 황금귤: 반짝이며 +50점
- 유채꽃: 7초 동안 귤이 돌돌이 쪽으로 끌려오는 자석
- 테왁(해녀의 주황색 부표): 생명 +1
그리고 귤을 계속 받으면 피버 게이지가 차고, 꽉 차면 '귤 폭풍 피버 타임'!
7초 동안 돌은 전부 황금귤로 바뀌고, 점수 2배, 무지개 빛이 쏟아지게 해 줘.
P 키로 일시정지도 되게 해 줘.
```

---

## 9단계 — 폴짝폴짝 점프! (게임이 단조로울 때)

```
게임이 좀 단조로워. 돌돌이가 폴짝 뛸 수 있게 해 줘.
- 스페이스, ↑ 키, 화면 탭으로 점프하고, 공중에서 한 번 더 뛰는 2단 점프도 되게
- 뛸 때는 몸이 위로 쭉 늘어나고, 착지할 때는 납작해지면서 흙먼지가 튀게
- 레벨 2부터 땅 위로 빨간 게가 옆으로 걸어와. 부딪히면 생명 -1,
  위에서 밟으면 +30점에 통 튕겨 오르고, 머리 위로 뛰어넘으면 +20점
- 가끔 날개 달린 귤 4개가 줄지어 하늘을 가로질러 날아가. 점프해야만 받을 수 있어
- 시작 화면 조작 안내에도 점프 방법을 추가해 줘
```

👀 확인: 2단 점프로 하늘 귤 행렬을 받고, 게를 밟아 튕겨 오르나요?
